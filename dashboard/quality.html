Качество данных и сверка

Можно ли доверять цифрам

Страница для команды данных и владельца источника. Цифры риск-сводки посчитаны по определению и не скорректированы; здесь — как они проверены и что в данных требует ответа источника.

  1. Сверка с источником в SQL: строки и суммы витрины пересчитываются заново от raw.*.
  2. Независимый пересчёт: метрики, разрезы, миграция и аномалии считаются второй раз из CSV на Python и сравниваются с данными дашборда до копейки.
  3. Проверка проверок: типичные ошибки нарочно вносятся в витрину — каждая обязана уронить свою проверку.
  4. Публикация после проверок: при любом FAIL данные для дашборда не выгружаются.

Аномалии данных

Подозрительные данные в витрине не исправляются. Для каждой аномалии — сколько кредитов затронуто, как изменились бы метрики при другой трактовке и вопрос к владельцу данных. Список кредитов — reporting.v_data_quality_issues.

Все проверки

FAIL — посчитать верно нельзя, данные не публикуются. WARN — данные подозрительные, но метрики посчитаны по определению. Источник — reporting.v_checks.
